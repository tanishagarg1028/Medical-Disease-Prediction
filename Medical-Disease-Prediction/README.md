## Final Setup

1. Extract Part1 into an empty folder.
2. Extract Part2 into the same folder.
3. Extract Part3 into the same folder.

## Install

pip install -r requirements.txt

## Run

python main.py

## Build EXE

pip install pyinstaller

pyinstaller --onefile --windowed main.py

The executable will be inside the dist folder.
